# ИИ-ассистент для персонализированного новостного дайджеста

Система собирает новости, понимает интересы пользователя и превращает поток RSS в короткий готовый дайджест.

Пайплайн собирает весь путь в одну систему и получается последовательная обработка превращает сырые веб-ленты в готовый структурированный отчет.
01: RSS-потоки, Habr и внешние новостные ленты.
02: Парсинг, сбор через feedparser и requests.
03: Очистка HTML и нормализация.
04: Выделяем теги, категории и метаданные статей.
05: Фильтрация Embeddings и cosine similarity.
06: Генерация DOCX
